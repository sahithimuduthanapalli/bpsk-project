# BPSK Modulation and Demodulation

This project simulates Binary Phase Shift Keying (BPSK) using Python.

## Features
- Binary data generation
- BPSK modulation
- Noise addition
- Signal demodulation
- Signal visualization

## Tools Used
- Python
- NumPy
- Matplotlib

## Output
The project generates modulated and noisy signals and recovers the original binary data.
